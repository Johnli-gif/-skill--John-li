# 财经热点操盘摘要面板

本项目是用户私有的 A 股交易辅助面板。它不登录券商、不读取账户后台、不自动下单；核心输入来自用户在 Codex 对话框上传的持仓截图、成交截图和明确确认的成交事实。

## 当前定位

面板只做三件事：

- 同步最新结构化持仓、成交和候选规则。
- 展示简版操盘摘要：市场闸门、持仓动作、触发提醒、下一候选方向。
- 配合 GitHub Actions 云端监控，在真实买入/卖出触发时发邮件提醒。

完整判断仍以 Codex 对话框中的 `caijing-redian-fenxi` skill 分析为准。面板是显示和提醒层，不是完整 AI 投研系统。

## 当前页面模块

1. `今日最终建议`：市场闸门、组合结论、逐只持仓动作、今日买入清单。
2. `当前持仓`：股票名称、代码、数量、成本、现价、盈亏和简短计划。
3. `触发提醒`：本地/云端触发状态，只提示真实可执行条件。
4. `下一候选方向`：全局候选赛道和候选股，不局限当前持仓。

旧版大工作台中的 30 天目标表单、仓位预算页、盘中手动检查清单、收盘复盘大表、独立截图接入和重复买入清单已取消或隐藏。

## 重要文件

- `PROJECT_STATE.md`：后续对话和开发的第一承接文件，优先读取。
- `CODE_MAP.md`：源码索引，后续改代码前先用它定位，不要默认读完整源码。
- `index.html`：四模块面板结构。
- `app.js`：核心状态、行情刷新、规则和渲染逻辑。文件较大，修改前用 `rg` 定位小范围。
- `styles.css`：面板样式，当前简版样式集中在 `.lean-*` 规则。
- `data/panel-sync.json`：对话框同步到面板的结构化数据源。
- `config/cloud-monitor-rules.json`：云端触发规则。
- `scripts/cloud_monitor.py`：GitHub Actions 云端行情监控和邮件提醒。
- `scripts/update_major_info.py`：重大财经资讯刷新脚本。
- `.github/workflows/ashare-monitor.yml`：云端定时监控 workflow。

## 低流量协作规则

后续新对话或继续任务时：

1. 先读 `PROJECT_STATE.md`。
2. 改代码前先读 `CODE_MAP.md`，不要默认读取完整历史对话、完整 `app.js`、完整 `styles.css` 或旧 README。
3. 普通持仓分析走 `fast_update`，只给紧凑结论。
4. 只有用户明确要求“详细分析/全市场扫描/赛道深挖/估值/回测”时才进入 `deep_scan`。
5. 每次重要项目变更结束后，更新 `PROJECT_STATE.md`，记录关键决策、已完成、待办、重要文件变化和架构边界。

## 云端提醒边界

GitHub Actions 只做公开行情和规则触发提醒，不做完整 AI 推理。生产邮件只在真实可执行条件触发时发送；无触发不发，部分股票触发只发对应股票。
